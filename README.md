# 🎬 FilmSense — Movie Recommender Application

**FilmSense** is a lightweight Python Desktop Application built with **Tkinter** and **Pandas** that randomly selects and recommends movies from an Excel database.

## 🚀 Features
- **Excel Dataset Integration**: Reads movie datasets directly from Excel (`.xlsx`).
- **Detailed Movie View**: Displays comprehensive movie details dynamically.
- **Interactive UI**: Includes a quick "Pick Another Movie" button for instant discoveries.
- **Watch Status Tracker**: Toggle and save watched/unwatched status directly back to the database.
- **YouTube Trailer Search**: One-click integration to launch YouTube trailers in your default browser.

## 🛠️ Requirements
- Python 3.x
- Pandas
- OpenPyXL (for reading `.xlsx` files)
